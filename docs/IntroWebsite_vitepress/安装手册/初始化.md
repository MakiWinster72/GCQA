# 初始化 Apache Answer

1. 浏览器访问

http://ip

> 若选择自编译，这里的端口 = INSTALL_PORT。若为 docker compose 则为 yaml 文件中的 ports

2. 选择语言

![](https://img.makis-life.cn/imagesNew/e3c541e5b7fabdda63eb92fa08c533cd_MD5.png?x-oss-process=style/yasuo)

3. 配置数据库

![](https://img.makis-life.cn/imagesNew/5076ee72b02a6b2f410c48136a0d6ae6_MD5.png?x-oss-process=style/yasuo)

**Docker Compose**

在 yaml 文件中已定义用户名密码和数据库名，数据库主机填容器名，注意端口为映射端口

**或使用主机的数据库**

```mysql
# 进入 MySQL 数据库
sudo mysql -u root

# -----------MYSQL-------------
# 创建 answer 的数据库
CREATE DATABASE answer;
# 创建用户名为 answer，主机为 localhost 的用户，并设置密码
CREATE USER 'answer'@'localhost' IDENTIFIED BY 'answer';
# 给 answer 用户对 answer 数据库的所有权限
GRANT ALL PRIVILEGES ON answer.* TO 'answer'@'localhost';
# 刷新权限
FLUSH PRIVILEGES;
# 退出 MySQL
EXIT;
```

4. 创建配置文件

> 点击下一步创建配置文件

![](https://img.makis-life.cn/imagesNew/08a9cbb660ecb3df65301d29c376702e_MD5.png?x-oss-process=style/yasuo)

联系邮箱和邮箱按需填写即可，不要求验证邮箱。

下一步后即进入网页。
