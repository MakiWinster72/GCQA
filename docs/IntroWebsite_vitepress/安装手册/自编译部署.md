## 自编译部署

相比 Docker 部署：我们单独为广财适配做了优化和改进

### 环境要求

| 工具    | 最低版本 |
| ------- | -------- |
| Golang  | 1.23     |
| Node.js | 20       |
| pnpm    | 9        |
| mockgen | 1.6.0    |
| wire    | 0.5.0    |

> 建议使用 Linux, 下以 ubuntu 为例

### 安装 Golang

由于 ubuntu 库中的 go 版本太低了，我们选择自行安装

下载 golang 安装包 => [链接](https://studygolang.com/dl)

如果之前安装过 go,请删除旧版本

```Bash
sudo rm -rf /usr/local/go
sudo rm -f /usr/bin/go
```

下载好安装包后开始安装

```Bash
sudo tar -C /usr/local -xzf go1.25.6.linux-amd64.tar.gz
```

修改环境变量，编辑`~/.profile`。（或 zprofile，如果使用 zsh）

```Bash
export GOROOT=/usr/local/go
export GOPATH=$HOME/go
export PATH=$PATH:$GOROOT/bin:$GOPATH/bin

# go 镜像代理
export GOPROXY="${GOPROXY:-https://goproxy.cn,direct}"
export GOSUMDB="${GOSUMDB:-off}"
```

保存退出后，应用环境变量`source ~/.profile`

测试是否安装成功

```Bash
go version
```

### 安装 NodeJs

```Bash
# Download and install nvm:
curl -o- https://raw.githubusercontent.com/nvm-sh/nvm/v0.40.3/install.sh | bash

# in lieu of restarting the shell
\. "$HOME/.nvm/nvm.sh"

# Download and install Node.js:
nvm install 24

# Verify the Node.js version:
node -v # Should print "v24.13.0".

# Verify npm version:
npm -v # Should print "11.6.2".
```

#### 安装 pnpm

```Bash
# 设置国内镜像代理
npm config set registry https://registry.npmmirror.com

# 安装pnpm
npm install pnpm
```

### 安装必要工具

```Bash
sudo apt update
sudo apt install git build-essential

# 如果下方指令无反应，则是go代理没起作用
go install -v github.com/golang/mock/mockgen@v0.6.0
go install github.com/swaggo/swag/cmd/swag@latest
go install github.com/google/wire/cmd/wire@v0.5.0
```

### 克隆项目

```Bash
git clone https://gh-proxy.com/https://github.com/MakiWinster72/GCQA.git
```

### 检查环境配置

```Bash
cd GCQA                                      # 进入项目
make check                                   # 检查项目环境配置

# 应当输出
# maki@vmwbuntu:~/GCQA$ make check
# v1.6.0
# swag version v1.16.4
```

### 构建

```Bash
# 编辑配置文件
vim conf/config.yaml
# 安装用于构建的 wire 和 mockgen。你可以运行 make check 来检查它们是否已安装。
make generate
# 安装前端依赖并构建
make ui
# 安装后端依赖并构建
make build
```

### 初始化

```Bash
sudo ./answer init
```

这时候打开浏览器输入 http://localhost (在主机）或 http://ip ，即可进入初始化界面
