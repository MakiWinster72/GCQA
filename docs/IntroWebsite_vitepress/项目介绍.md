# GCQA - 为广财打造的 Q&A 平台

基于 Apache Answer, 为广财打造的 Q&A 平台。解决当前老师/同学们获取信息需要寻找众多咨询群、通知群、融合门户等方式来获取信息的痛点，提供一个统一的 Q&A 平台，让同学、老师可以方便地获取和分享信息。

Live Demo: [https://gcqa.makis-life.cn](https://gcqa.makis-life.cn)

> Demo仅测试开放

有关 Apache Answer, 请查阅 [answer.apache.org](https://answer.apache.org).

## 主要改进

以下说明基于 Answer 主要改进的功能

### 企业微信插件

默认集成了企业微信插件，可以直接在微信中扫码注册登录。
需要用户的微信属于管理员所配置的企业。

<img alt="logo" src="https://img.makis-life.cn/imagesNew/loginInWechat.gif" style="height: 90vh; width: auto">

### 预设问题

管理员可以在`后台管理`>`内容管理`>`预设问题`中添加预设问题。例如可以要求用户确认已经尝试搜索类似问题或询问相关人员。

**用户提问界面**
![](https://img.makis-life.cn/imagesNew/77192da809e6a2f7c5b661cbb90cfc26_MD5.webp?x-oss-process=style/yasuo)

**展示效果**
![](https://img.makis-life.cn/imagesNew/a3dd370517fb16b1051e7c43c9d81a38_MD5.webp?x-oss-process=style/yasuo)

### 改进分享

删除了 Facebook 和 X 选项，新增`分享到微信`以及`二维码`

![](https://img.makis-life.cn/imagesNew/7ebd73af83b061ee2ac195871cf3f202_MD5.webp?x-oss-process=style/yasuo)

### 优化最佳答案外观

添加了最佳答案的突出显示，让最佳答案更易于识别。

![](https://img.makis-life.cn/imagesNew/1a8350cb295ea315bb9dac86e246feb9_MD5.webp?x-oss-process=style/yasuo)
