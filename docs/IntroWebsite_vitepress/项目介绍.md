# GCQA - 为广财打造的 Q&A 平台

基于 Apache Answer, 为广财打造的 Q&A 平台。解决当前老师/同学们获取信息需要寻找众多咨询群、通知群、融合门户等方式来获取信息的痛点，提供一个统一的 Q&A 平台，让同学、老师可以方便地获取和分享信息。

预览测试: [https://gcqa.makis-life.cn](https://gcqa.makis-life.cn)

> Demo 仅测试开放

有关 Apache Answer, 请查阅 [answer.apache.org](https://answer.apache.org).

## 当前痛点

在同学们遇到问题的时候，有时不知道在哪里咨询、去哪里查找提问。现有的沟通方式主要依赖 QQ 群以及辅导员，存在以下突出问题：
1、信息分散、渠道不明：部分同学不知道应该加入哪个群、哪个群是学校官方渠道，经常遇到群号过期、二维码失效、群满员无法加入等问题；

<img src="https://img.makis-life.cn/imagesNew/IMG_6708.PNG?x-oss-process=style/yasuo"
     style="max-width: 400px; width: 100%; height: auto;" />

<img src="https://img.makis-life.cn/imagesNew/IMG_6709.PNG?x-oss-process=style/yasuo"
     style="max-width: 400px; width: 100%; height: auto;" />

2、当前提问效率低：在 QQ 群中提问，消息多时**容易被忽略**；**QQ 群有人数上限**，部分同学无法入群，并且管理人员需要在群满时清理不活跃帐号，可能还有垃圾广告造成不良影响；

<img src="https://img.makis-life.cn/imagesNew/IMG_6714.PNG?x-oss-process=style/yasuo"
     style="max-width: 400px; width: 100%; height: auto;" />

3、如财务部、教务处等部门目前需通过 QQ 群答疑，老师必须登录电脑 QQ 才能回复，**受限于设备和时间**，响应不及时。

4、及时要求先看公告、通知等再提问，依然会有非常多的同学提问重复的问题。

### 问答平台可解决以上问题：

1. 统一入口，使用网页访问，用户、支持人员可通过任意支持浏览器的设备访达，**无限制人数上限**；
2. 若配置企业微信登录，可有效防止垃圾广告，支持微信提醒，老师/同学可以在微信点击链接**快捷跳转直达问题**，提高解决问题的效率；
3. **热心同学也可参与回答**，老师/部门可补充细节以及明确采纳同学的答案，提高校内互助氛围；
4. 有搜索以及智能 ai（需管理员配置），同学们在搜索前可以尝试搜索是否存在相似的问题，也可以询问 ai，ai 会自动搜索已存在的提问综合回复。

## 功能介绍

### 首页界面

![](https://img.makis-life.cn/imagesNew/Screenshot%202026-02-28%20at%2023-04-06%20%E5%B9%BF%E4%B8%9C%E8%B4%A2%E7%BB%8F%E5%A4%A7%E5%AD%A6%E9%97%AE%E7%AD%94%E5%B9%B3%E5%8F%B0.png?x-oss-process=style/yasuo)

### 创建问题

![](https://img.makis-life.cn/imagesNew/create-edited.png?x-oss-process=style/yasuo)

![](https://img.makis-life.cn/imagesNew/tags.png?x-oss-process=style/yasuo)

任何角色都可以创建问题，创建问题时有以下内容需要填写：

1. **问题标题**（大于 6 字符）
2. **预设问题**（管理员可在后台配置）  
   预设问题可被管理员在**后台管理**中配置，有单选、多选、填空。
3. **问题内容** （大于 6 字符）
   支持 Markdown 语法，方便长问题的排版。  
    支持图片、视频、文件，具体设置可由管理员在后台管理配置，可限制上传文件的后缀，单个图片/文件的大小。
4. **标签**  
   对问题的分类，可分配某一问题给对应的部门解决，如财务处对应财务标签。  
   标签拥有链接标记，如**财务**分配`financial`，则所有财务标签的问题均在`域名/financial/问题ID`
5. **秘密信息**  
   此处的内容<u>仅本人、版主和管理员可见</u>，用于在回答问题时附加一些必要的但涉及隐私的信息，比如学号、电话号码、邮箱等
6. **回答自己的问题**  
   开启回答自己的问题后，会多一个内容填写框，便于版主/管理员发布示例问题或热门问题的回答。

### 问题详情页面

问题内容为示例，在财务群中获取：

![](https://img.makis-life.cn/imagesNew/detail-cutted.png?x-oss-process=style/yasuo)

问题与回答均支持图片、视频和文件。  
同学们可对问题以及回答进行点赞与踩、添加评论、添加小表情，“踩”只有后台可见。可侧面反映出同学们对该问题的关注度。  
被采纳的问题会有突出的效果。  

#### 问题管理

![](https://img.makis-life.cn/imagesNew/share.png?x-oss-process=style/yasuo)

每个问题均可被分享、举报、编辑、删除。

此处我们对上游仓库进行了修改，分享内容修改为“复制链接”以及“复制到微信”（手机点击可跳转至微信 weixin:// ）以及“二维码”（即用二维码存储了当前网址，微信/手机相机扫描可快速直达当前网页，<u>上图二维码扫码结果是上上图的问题界面</u>）

当问题出现不当内容时，用户可举报问题。管理员会受到举报通知，可前往审核，对问题进行保留/删除，并且对用户进行警告或直接禁用该账号。

编辑与删除只有本人、版主、管理员可以设置。

### AI 助手

![](https://img.makis-life.cn/imagesNew/aiAnswer.png?x-oss-process=style/yasuo)

管理员可在后台中配置智能 AI,当前支持 OpenAI、Claude、DeepSeek。
智能 AI 可<u>自动查询</u>数据库中已经存在的类似的问题、相应问题的内容、以及是否存在采纳答案，然后综合回答用户的问题。  
可以非常有效地解决同学们重复提问的现象。

### 标签

![](https://img.makis-life.cn/imagesNew/tagspage.png?x-oss-process=style/yasuo)

标签相当于问题的分类，每个问题被创建时需要被分配至少一个标签。目前我们测试仅想到以下推荐标签：

`财务`、`选课与课程`、`考试`、`其他`

对于“其他”，是为了方便同学们在创建问题时觉得现有标签并无符合当前问题内容时选择，当带有“其他”标签的问题过多时，管理员/版主应当考虑增加相应的标签。  
“生活”标签，我们暂不确认是否允许有关生活的提问，一些住宿类问题等是合理的，但可能会有过多老师/部门无法回答的问题，比如饭堂、失物招领等。这个标签应有待考虑是否添加。

#### 关注标签

用户可关注某个标签。  
应用场景：分配部门/老师关注某个标签，比如财务处关注`财务`标签，如果管理员配置了 SMTP 或企业微信，则可以在有标签有新问题时获得提醒：

![](https://img.makis-life.cn/imagesNew/IMG_6690.PNG?x-oss-process=style/yasuo)

![](https://img.makis-life.cn/imagesNew/IMG_6691.PNG?x-oss-process=style/yasuo)

> 微信中点击可快速跳转到对应问题详情界面。

## 后台管理

### 问题管理

![](https://img.makis-life.cn/imagesNew/questionManage.png?x-oss-process=style/yasuo)

![](https://img.makis-life.cn/imagesNew/answerManage.png?x-oss-process=style/yasuo)

管理员在`后台管理`>`内容管理`>`问题`中可以查看到所有“问题”的状态，方便审查问题和回答的内容、未解决的问题、管理已关闭已删除的问题。

#### 企业微信

![](https://img.makis-life.cn/imagesNew/wecom.png?x-oss-process=style/yasuo)

管理员可在此处配置企业微信，配置成功后，同学们可不再需要注册账号，通过企业微信即可登录问答平台。  
实现了一人一号，有效防止垃圾广告。

#### SMTP

![](https://img.makis-life.cn/imagesNew/smtp.png?x-oss-process=style/yasuo)

管理员可在`后台管理`>`高级选项`>`SMTP`中配置 SMTP，成功后用户可以启用邮箱提醒。
