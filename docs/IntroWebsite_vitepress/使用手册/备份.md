# 备份

## Mysql

使用 mysql dump 即可

```Bash
# 导出 answer 数据库为 answer.sql
mysqldump -u answer -p answer > answer.sql
```

请注意要备份 uploads 文件夹的媒体文件

## Docker

进入容器

```Bash
docker ps                           # 查看 answer 容器名
docker exec -it (容器名) /bin/bash   # 进入容器
./answer dump                       # 导出数据库为sql文件，默认为当前路径
```

> [!warning] 注意
> 同时也要备份 uploads 文件夹，数据库不包含媒体文件。
