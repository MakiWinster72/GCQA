# 配置域名

## 域名解析

在域名解析中添加 A 记录，指向服务器 IP 地址。例如主机记录为 gcqa 和 <www.gcqa> 。下图为阿里云域名解析的配置界面：

![](https://img.makis-life.cn/imagesNew/01908ef91a3dbcdaa4e115e5341708a9_MD5.png?x-oss-process=style/yasuo)

## 配置 SSL 证书

以阿里云为例，在数字证书管理服务中，为域名创建一个 ssl 证书

![](https://img.makis-life.cn/imagesNew/b566a64232aba66b8c3cc1baad36b6e2_MD5.png?x-oss-process=style/yasuo)

证书颁发后，下载证书文件

![](https://img.makis-life.cn/imagesNew/b34ac61a699ae98fd7ec3ca7dfa0b9f5_MD5.png?x-oss-process=style/yasuo)

上传到服务器中，比如`/etc/nginx/ssl/`

## Nginx

### 安装 nginx

```Bash
sudo apt install nginx
```

### 更新配置文件

```Bash
sudo vim /etc/nginx/sites-available/default
```

参考如下

```Bash
server {
    listen 80;
    # TODO: 修改为对应的域名
    server_name gcqa.gdufe.edu.cn www.gcqa.gdufe.edu.cn;

    # 强制将 HTTP 请求重定向到 HTTPS
    return 301 https://$host$request_uri;
}

server {
    listen 443 ssl;
    # TODO: 修改为对应的域名
    server_name gcqa.gdufe.edu.cn www.gcqa.gdufe.edu.cn;

    # TODO: 配置 SSL 证书路径
    ssl_certificate /etc/nginx/ssl/gcqa.gdufe.edu.cn.pem;
    ssl_certificate_key /etc/nginx/ssl/gcqa.gdufe.edu.cn.key;

    # SSL 配置（协议和加密套件）
    ssl_protocols TLSv1.2 TLSv1.3;
    ssl_ciphers 'ECDHE-ECDSA-AES128-GCM-SHA256:ECDHE-RSA-AES128-GCM-SHA256:ECDHE-ECDSA-AES128-SHA256';
    ssl_prefer_server_ciphers off;

    # 反向代理到 answer
    location / {
        proxy_pass http://127.0.0.1:8080;   # TODO: 这里要对应 answer 的安装端口
        proxy_set_header Host $host;
        proxy_set_header X-Real-IP $remote_addr;
        proxy_set_header X-Forwarded-For $proxy_add_x_forwarded_for;
        proxy_set_header X-Forwarded-Proto $scheme;
    }
}
```

### 运行 Nginx

```Bash
sudo nginx -t                      # 检查配置文件语法
sudo systemctl restart nginx       # 重启Nginx
```

现在访问 <https://域名> 应当就能进入问答平台界面了。
