## 企业微信登录

前提要完成[配置域名](配置域名.md)。

管理员在`后台管理` > `插件` > `已安装插件` 中启用 `企业微信` 插件

### 创建 app

扫码选择管理员**账号** https://work.weixin.qq.com/

![](https://img.makis-life.cn/imagesNew/e112b01bb72ed0da34f7cd0055b6ee6d_MD5.png?x-oss-process=style/yasuo)

在此处创建一个新的应用，例如叫 广东财经大学问答平台

获取 **AgentId** 和 **Secret**，Secret 要求只能在手机上查看。

### 获取企业 ID

![](https://img.makis-life.cn/imagesNew/13edaaa96ae8bb74300c5d69d458ba66_MD5.png?x-oss-process=style/yasuo)

### 填写插件信息

返回问答平台，进入后台管理 > 插件 > 企业微信，填写刚刚的三个数据。

点击保存，先别点击同步联系人，还需要配置。

### 添加可信 IP

回到企业微信管理后台，进入刚刚创建的 app，添加服务器的 IP 地址。

![](https://img.makis-life.cn/imagesNew/5ecca130985ddcc0a22751ea78159e97_MD5.png?x-oss-process=style/yasuo)

### 授权回调域名

![](https://img.makis-life.cn/imagesNew/0777bbc7be84f9cfba89153b9a91ce08_MD5.png?x-oss-process=style/yasuo)

![](https://img.makis-life.cn/imagesNew/a760819f08586515d318e82fb7b7dc24_MD5.png?x-oss-process=style/yasuo)

此处设置可信域名需要完成**域名归属认证。**下载他提供的文件，传输到服务器中。

连接至服务器，将 nginx 的配置临时设置为:

`sudo vim /etc/nginx/sites-available/default`

```Bash
# HTTP 跳 HTTPS
server {
    listen 80;
    server_name gcqa.gdufe.edu.cn www.gcqa.gdufe.edu.cn;

    location = /WW_verify_6tELZTqYnpavJNAe.txt {   # 这里这个是文件名
        root /etc/nginx/website;
    }

    location / {
        return 301 https://$host$request_uri;
    }
}

# HTTPS 提供验证文件
server {
    listen 443 ssl;
    server_name gcqa.gdufe.edu.cn www.gcqa.gdufe.edu.cn;

    ssl_certificate /etc/nginx/ssl/gcqa.gdufe.edu.cn.pem;
    ssl_certificate_key /etc/nginx/ssl/gcqa.gdufe.edu.cn.key;

    ssl_protocols TLSv1.2 TLSv1.3;
    ssl_ciphers 'ECDHE-ECDSA-AES128-GCM-SHA256:ECDHE-RSA-AES128-GCM-SHA256:ECDHE-ECDSA-AES128-SHA256';
    ssl_prefer_server_ciphers off;

    location = /WW_verify_6tELZTqYnpavJNAe.txt {   # 这里这个是文件名
        root /etc/nginx/website;   # 将归属认证文件传输到本文件夹中
    }

    location / {
        return 404;
    }
}
```

然后重启 nginx

`sudo systemctl restart nginx`

尝试 http://域名/文件名 ，应当能看见归属认证文件的文本内容。

返回企业微信后台此处，填写可信域名后，点击确认，即可添加成功。

![](https://img.makis-life.cn/imagesNew/6f41caa96eec92f3967c5ff5e712943b_MD5.png?x-oss-process=style/yasuo)

重新恢复 Nginx：

```Bash
server {
    listen 80;
    # TODO: 修改为对应的域名
    server_name gcqa.gdufe.edu.cn www.gcqa.gdufe.edu.cn;

    # 强制将 HTTP 请求重定向到 HTTPS
    return 301 https://$host$request_uri;
}

server {
    listen 443 ssl;
    # TODO: 修改为对应的域名
    server_name gcqa.gdufe.edu.cn www.gcqa.gdufe.edu.cn;

    # TODO: 配置 SSL 证书路径
    ssl_certificate /etc/nginx/ssl/gcqa.gdufe.edu.cn.pem;
    ssl_certificate_key /etc/nginx/ssl/gcqa.gdufe.edu.cn.key;

    # SSL 配置（协议和加密套件）
    ssl_protocols TLSv1.2 TLSv1.3;
    ssl_ciphers 'ECDHE-ECDSA-AES128-GCM-SHA256:ECDHE-RSA-AES128-GCM-SHA256:ECDHE-ECDSA-AES128-SHA256';
    ssl_prefer_server_ciphers off;

    # 反向代理到 answer
    location / {
        proxy_pass http://127.0.0.1:8080;   # TODO: 这里要对应 answer 的安装端口
        proxy_set_header Host $host;
        proxy_set_header X-Real-IP $remote_addr;
        proxy_set_header X-Forwarded-For $proxy_add_x_forwarded_for;
        proxy_set_header X-Forwarded-Proto $scheme;
    }
}
```

重启 Nginx

`sudo systemctl restart nginx`
