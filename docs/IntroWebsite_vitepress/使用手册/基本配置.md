# 基本配置

## 配置文件

config/config.yaml

```YAML
server:
  http:
    addr: 0.0.0.0:80                          # 项目访问端口号，小于1024需要sudo
data:
  database:
    driver: "mysql"                           # 默认数据库驱动为 mysql
    connection: root:root@tcp(127.0.0.1:3306)/answer # MySQL 数据库连接地址
  cache:
    file_path: "/tmp/cache/cache.db"          # 缓存文件存储路径
i18n:
  bundle_dir: "/data/i18n"                    # 国际化文件存储目录
swaggerui:
  show: true                                  # 是否显示 swaggerapi 文档，地址为 /swagger/index.html
  protocol: http                              # swagger 协议头
  host: 127.0.0.1                             # 可访问的 IP 地址或域名
  address: ':80'                              # 可访问的端口号
service_config:
  upload_path: "/data/uploads"                # 上传目录
ui:
  public_url: '/'                             # 静态资源路径
  api_url: '/'                                # ajax 请求的 api url
  base_url: ''                                # 默认部署在根目录下，当部署在子目录时需要修改此值
```

## 添加用户

目前分为三种方式新增账号：邮箱注册、企业微信、管理员手动新增。

### 邮箱注册

在配置好**SMTP**后，确保在`后台管理`> `高级选项` > `登录` 里面打开允许邮箱注册。

![](https://img.makis-life.cn/imagesNew/b04726431d6c171d8114b67417b9ba3a_MD5.png?x-oss-process=style/yasuo)

此时在注册界面即可使用邮箱注册。

![](https://img.makis-life.cn/imagesNew/1ef636c154c8723ae3f300be30c24214_MD5.png?x-oss-process=style/yasuo)

### 企业微信

需要在`后台管理` > `插件` > `已安装插件`中开启企业微信插件。

启用后，配置好信息，在注册界面即会出现`连接至企业微信`，可使用微信扫码登录。

![](https://img.makis-life.cn/imagesNew/83d3c2486f998a8fbc87a1f6bbea6ec0_MD5.png?x-oss-process=style/yasuo)

### 手动新增

在`后台管理` > `社区` > `用户管理`中，选择`添加用户`

用逗号分隔“name, email, password”，每行一个用户。

![](https://img.makis-life.cn/imagesNew/56fd9714b04b77f19eac5a38c6571e8a_MD5.png?x-oss-process=style/yasuo)

## 用户管理

在`后台管理` > `社区` > `用户管理` 里面，可以对现有的用户进行管理。

![](https://img.makis-life.cn/imagesNew/87907507f9a6a3201de8b75e805388a4_MD5.png?x-oss-process=style/yasuo)

### 角色

系统共设计了三个角色：用户、管理员、版主。

默认角色：用户。

版主拥有除后台管理外所有功能。

**推荐：**

部门账号/部分老师可以设置为版主，管理人员设置为管理员。

## 规则

![](https://img.makis-life.cn/imagesNew/30ef7cd2861642b1ee6d1dc3d97a09b2_MD5.png?x-oss-process=style/yasuo)

这里的声望是用户活跃度和可信度的标志。

该设置的意义为筛选出优质用户，并使其拥有更高的可信度以及分配部分权利，例如编辑他人问题无需审核等。

可以在初期选择**级别 2**，在运行一段时间后升级为**级别 3**。

## 标签

标签是同一类问题的集合，用户可以关注标签，在标签下有新问题时获得消息提醒（需配置 SMTP 或企业微信）

![](https://img.makis-life.cn/imagesNew/7f0d5e13f662fa23146eae0c87cd2eed_MD5.png?x-oss-process=style/yasuo)

### 创建标签

管理员可以创建标签，在上图中点击`创建标签`进入下图界面

![](https://img.makis-life.cn/imagesNew/c72e8da49bab92b3b529c1b9dce057e4_MD5.png?x-oss-process=style/yasuo)

例如填写:

**显示名称**

财务

**URL** **固定链接**

financial

**概述**

该标签用于咨询财务问题，包含学费、医保、学分费等缴费退费问题。

则有如下效果:

进入 <https://域名/tags/fiancial> 即为该标签下所有问题。

![](https://img.makis-life.cn/imagesNew/d598cfb33c9901398b4d2f5676b9ede6_MD5.png?x-oss-process=style/yasuo)

应用场景如：

1. 财务处仅关注本标签。
2. 为特定事件活动设定标签如校运会，同学们可在此集中查看有关校运会的问答。

### 保留标签与推荐标签

管理员可以在`后台管理` > `内容管理` > `标签`中设置保留标签与推荐标签

##### 保留标签

保留标签是指只有版主才能选择的标签，普通用户无法选择。

适合由部门/管理员发布一些重要的提醒/问题

##### 推荐标签

推荐标签是在创建问题时会出现在用户下拉菜单中的选项。

![](https://img.makis-life.cn/imagesNew/089be9d7d71e1ca43d90704e4421fdf0_MD5.png?x-oss-process=style/yasuo)

## 自定义 CSS

在后台管理>外观>自定义中，可以输入自定义 CSS，分别在头部/页眉/侧边栏/页脚插入 CSS。

其中**侧边栏**会出现在以下地方

![](https://img.makis-life.cn/imagesNew/9e62e113c5830dafd2649e9903ea0dc4_MD5.png?x-oss-process=style/yasuo)

### 侧边栏内容（参考）

> 使用 html，可加入公告内容，学校链接之类。

```html
<hr />
<aside class="qa-sidebar">
  <section class="sidebar-card">
    <strong>提问请注意:</strong>
    <p>优先使用搜索功能，可能问题已经被解答</p>
    <p>描述你已经尝试过的方法或遇到的错误</p>
    <p>必要时请附上截图</p>
  </section>

  <section class="sidebar-card">
    <strong>近期常见问题</strong>
    <p>...</p>
  </section>
  <section class="sidebar-card sidebar-tip">
    <p>已解决的问题记得点「采纳」，可以帮助到更多同学</p>
  </section>
</aside>
<hr />
```
